## Architecture

1. CI uses the existing process supervisor to record Rust phases and three distinct race iterations. Preserve the whole-job 30-minute limit, three iterations, eight race-test threads and actual failure/signal status. Distinguish the last completed test from occasional reported slow tests; output does not identify every active test. Do not invent the old timeout's cause.
2. Masking uses a conservative trigger check before the unchanged regex engine. Every accepted secret shape must still reach that engine. Compare complete output and counts against the original algorithm; performance is measured on identical synthetic input before/after. No privacy-policy change or dependency is needed.
3. Unknown liveness may carry structured possible-process evidence. It remains Unknown, never authorizes Running/resume/stop, and never picks an arbitrary process from multiple candidates. Preserve direct, compact-wire and hydrated-list paths, old payload compatibility, and mirrored Rust/TypeScript types. Display in the actual transcript header and session list.
4. Transcript percentage navigation resolves server-side to a bounded record-aligned page using the current position index or an honest bounded fallback. The UI commits a seek only on release/keyboard confirmation, supersedes old navigation, scrolls to a returned message and stays detached from live follow even at EOF. Latest explicitly reattaches. Estimates are announced as estimates. Empty, rewritten, huge-record and older-host cases are handled without whole-file UI reads or guessed cursors.
5. Field diagnostics reuse existing opt-in settings and log/export UI, adding a bounded allowlisted measurement journal where existing tail retention is insufficient. Records carry build/schema, epoch/timing, explicit loss/coverage and opaque scoped correlation. No private organization/repository/path/PR/session text, titles, authors or credentials may appear in the new shareable export. No unsalted identifier hashes. Disabled diagnostics must not format/allocate substantial data; enabled diagnostics add no provider requests, scan demand or write authority. Files, memory, cardinality, event volume and export reads have explicit caps; recorder failures cannot break user work. New measurement functions distinguish missing from zero and proxies from paint or memory attribution.
6. Producers observe real native admission/publication/cache/backfill and frontend mounted-view outcomes; diagnostics must explain accepted versus rejected stale facts and retained coverage without per-row logging storms. Capture StopFailure/turn-end deltas before the current15-second classifier; retain out-of-window and unmatched observations. Do not retune that threshold until actual evidence supports a change. The user gets a single shareable log/export plus an offline summary and concrete desktop/iPhone steps.
