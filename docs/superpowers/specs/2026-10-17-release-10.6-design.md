## Behavior
- #1866: distinguish successful bounded progress, pause, busy admission, cancellation, timeout and supersession from real read/write failures. Carry actual IO/SQL failures separately from cooperative stop/invalidation causes, including mixed fault-plus-stop results. Only actual faults increment operational failure counts. Index warnings describe search coverage, never claim history/crash detection failed when those succeeded. Partial coverage remains truthful.
- #1867: choose the documented until-explicit-import pause lifetime. Persist pause before cancellation acknowledgment; reload it at every automatic admission, including after restart. An ordinary page mount must not resume. Rescan explicitly resumes and transactionally clears pause. Old cancelled jobs stay cancelled. History/crash collection continues while corpus work is paused or busy.
- #1868: all incremental link reads participate in cancellation/deadline checks and link-generation ownership. Accepted graph reset invalidates older link workers. Read outside write transactions; atomically publish links/cursor only under an immediate transaction with generation/control checks. Cancellation is cooperative between bounded IO units: a commit linearized before cancellation is allowed, but none may publish after its database fence.
- #1869: cap per-lane work and durably rotate the first lane, sharing cancellation and the enclosing deadline so expensive usage cannot repeatedly keep indexing last. Retain the existing 60-second pass/discovery ceiling rather than introducing a tighter nonresumable discovery limit. Persistently rotate the first processing lane across links, metadata, usage and index. Give processing lanes at most 10/10/15/25 seconds respectively, capped by the enclosing deadline. Rotation guarantees later lanes get an early turn after an expensive earlier lane; normal discovery must complete for this guarantee. Discovery continuation for a listing exceeding the existing ceiling is a separate limitation, not solved by retrying a tighter prefix. Blocking OS IO remains cooperative, not forcibly interruptible. These are chosen limits, not measured performance claims. Retain existing per-file retry fairness; never publish partial usage as complete.
- #1882: partial listings retain omitted checkpoints; prune only on complete authoritative discovery.
- #1883: malformed/database-failed link cursors report errors, not absent baseline; no destructive reset.
