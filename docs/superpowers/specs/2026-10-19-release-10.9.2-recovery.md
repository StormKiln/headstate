# 10.9.2 delivery recovery (#1915)

## Evidence and scope

10.9.1 passed PR, merge-group, main and tag CI but was not published. Its universal macOS app compiled, signed and received Apple notarization acceptance. The subsequent DMG script failed after 17 seconds with only a generic error. Linux and Windows release jobs succeeded; publication was skipped. The failed tag remains immutable. The owner authorized 10.9.2 as the replacement release.

The pinned Tauri CLI 2.11.4 [DMG bundler](https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.11.4/crates/tauri-bundler/src/bundle/macos/dmg/mod.rs) calls [output_ok](https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.11.4/crates/tauri-bundler/src/utils/mod.rs), which logs subprocess stdout/stderr only at debug level and returns a generic failure. This establishes the diagnostic defect. The actual hosted DMG subcommand/trigger remains unknown; neither Finder, hdiutil contention nor disk exhaustion is claimed as its cause.

## Correction

The existing CI command collector has an opt-in `--release` mode. Narrowly scoped Tauri command debug output is consumed in memory; no raw text, arguments, environment or paths are emitted or retained. Only fixed DMG phase names, allowlisted hdiutil operation/reason enums, timestamps, byte/line counts, process ID and exit status reach logs/artifacts. Unknown causes remain `unknown`, and other lines are counted and discarded. Lines above 64 KiB are discarded in full. Two rotating 2 MiB files bound retained classifications. Default collector behavior and process-group cancellation/exit handling remain intact.

A raw-log/redaction proposal was rejected by automatic approval review and was replaced before any workflow change with this fixed-field design. This deliberately loses unclassified details rather than risking credential retention. No shell tracing or raw signing-log artifact was added.

macOS release packaging uses the collector and retains its fixed-field artifacts even on failure. The ordinary CI build now also creates a real native-architecture DMG from the app it already built, so this packaging path is exercised before tagging. This is not a replacement for the universal signed/notarized release checks. No retries, timeout increases or publication-gate exemptions were added.

## Local verification

The collector tests initially failed for the missing release mode. All 11 tests now pass, including failure/success statuses, split and multiline synthetic credentials, oversized lines, unknown error text, bounded rotation retaining the final failure, and existing cancellation/descendant/native-signal behavior.

Two probes used an isolated copy of the existing public 10.9.0 universal binary with the pinned Tauri bundler, signing disabled and updater generation disabled only for these local probes. No personal app or synthetic dataset was replaced.

- Injected `hdiutil` failure: fixed `create / resource-busy` classification captured and Tauri exit 1 preserved. This is a controlled error, not the hosted cause.
- Actual system `hdiutil`: DMG creation completed through create/mount/link/permissions/compress phases, exit 0, 19.3 seconds. This does not claim notarization of the local probe or explain the prior hosted failure.

Full gate and publication outcomes are recorded on #1911/#1915 and the recovery PR. Desktop 10.9.2 includes the merged #1912/#1913 corrections from the unpublished 10.9.1. Companion remains 10.9.0 build 53; no production application/shared/mobile inputs changed. Enterprise, physical-device and spontaneous native-crash acceptance remain open.
