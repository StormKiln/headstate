# 10.9.1 closeout evidence

## Reproduced correction (#1912)

The previous `qualified(result)` accepted NaN, positive infinity and boolean memory readings. New adversarial tests initially reported 28 failing subcases and 12 errors across five test methods. The correction requires the producer's numeric domains: positive signed-32-bit PIDs and positive UInt64 integer byte counts, with booleans excluded. Malformed containers return false. Ordered phases, visibility and stable distinct identities remain mandatory. All five methods now pass, including numeric boundary and malformed-input cases; the suite is included in the ordinary script/CI gate.

This fixes a developer evidence validator, not a demonstrated production memory regression. The Swift/C producer already emits integer PID and UInt64 memory readings. No application/provider polling, cache, database, shared frontend, mobile or protocol code changed.

Follow/growth phases were not rerun by this invocation.
