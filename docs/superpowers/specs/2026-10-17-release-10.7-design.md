## Behavior and design

Health history must return at most 120 chronological observations. Keep all small histories and sample large histories evenly including both oldest and newest. Preserve missing readings and actual timestamps; never manufacture zeroes.

FTS maintenance needs indexed identity lookup. Add a one-to-many session-to-FTS-rowid table (rowid primary key, indexed nullable session identity) through a numbered transactional migration, populated from existing FTS rows without discarding content. Maintain mapping and FTS body/masked body/ledger together; removal and replacement use rowid. Migration preserves every existing FTS row, including duplicate and nullable identities; successful authoritative replacement removes all mapped rows for its session. Prove rollback and partial-discovery behavior remain intact.

Session ordering remains NULL-last last_activity_at DESC, first_seen_at DESC. Align its index with equivalent ordering. Runs must still group all sessions correctly and keep newest runs first within each group; preserve cross-session liveness evidence. Use bundled SQLite query plans and measured write/storage costs to choose indexes.

Derived graph publication remains one fenced transaction. Deduplicate desired keys with the existing last-incoming-value semantics, then apply semantic set differences rather than clearing both graph tables. Identical complete snapshots cause zero mutations to graph tables. Preserve first_seen_at semantics; resolved_at means last attribution change, not last unchanged scan. Partial discovery retains old edges; changed and removed edges converge atomically. Cursor reset remains coupled to accepted authoritative publication.

PR-link checkpoints must retain source continuity, unresolved parser evidence, cancellation/generation fences and atomic link/checkpoint publication. Measure current serialization, WAL and memory costs using synthetic data. Prefer per-source checkpoint rows and changed-row publication so one file does not rewrite the corpus. Compact checksum storage if measured beneficial. Do not silently evict unresolved evidence or add an arbitrary retention cap that loses correctness. Strict legacy migration must retain old evidence until successful atomic conversion, using a distinct baseline marker and preserving offset-only entries. Reset is atomic even without an outer transaction; failure-injection tests must target the new persistence tables. Warm unchanged sources must still read zero body bytes. Bound serialization work to changed sources; report remaining proportional storage honestly.
