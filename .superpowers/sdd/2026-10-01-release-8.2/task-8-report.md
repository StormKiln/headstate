# Task 8 — Native Markdown export (#1529)

Base: `c3ae6060dbb759d8109c9f6a0e44eaafd3b975df`.

## Implementation

Shared mounted export controls now save the current resident Markdown or selected turns through a local `save_markdown` command. The existing formatter supplies exactly the same text and unloaded-history qualifications as clipboard export; no history reads are introduced. The mobile build says Share and desktop says Save. The mounted phone Reveal owner disables both clipboard and native export and explains how to return to masked export. The command is client-local in frontend routing and both Rust surface tables.

The payload limit is 8 MiB of UTF-8, checked before IPC and natively. Desktop uses a parented native dialog, neutral `transcript.md`, quiet cancellation, one in-flight operation, and a same-directory tempfile followed by atomic replacement. Failed staging/replacement leaves the original destination intact. The owned asynchronous operation survives caller cancellation. Dialog 2.7.3 and its FilePath dependency fs 2.5.2 are pinned to preserve the existing Tauri 2.11.5 lock; the initially selected newer dialog would have upgraded Tauri and was corrected before final verification. tempfile 3.27 was already an approved test dependency and is now also used in production.

The in-repo mobile plugin presents UIKit's activity sheet on main with an iPad popover anchor and once-only completion. Android uses a private cache FileProvider, read grant, ClipData and the activity-result callback. Its distinct provider subclass preserves Tauri's existing provider. Both platforms retain immutable app-owned files for a 24-hour lease and reuse byte-identical content, renewing that lease. Capacity is eight files / 32 MiB; distinct exports at capacity fail with an actionable copy/reuse fallback instead of deleting still-shareable files. Cleanup occurs on subsequent exports and touches only expired owned hash directories. Returning from an Android chooser reports `presented`, never saved. Rust owns the native bridge future until its callback, avoiding Tauri's dropped-oneshot callback panic. No transcript content or selected destination is logged.

## Permanent native gates

Both existing required mobile CI jobs now invoke actual native compilation. The script discovers declared native packages, refuses missing/empty inventories, compiles their real source against lock-resolved Tauri APIs, and preserves output outside the checkout. The separate bridge-name guard remains required. Android also assembles a minimal host APK with both the ordinary and export providers and verifies the merged policies. This caught a real integration failure that library assembly alone missed.
